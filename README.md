# AstroSage Call Analytics

An Excel-based Call Centre Analytics project focused on analyzing call trends, guru performance, customer satisfaction, consultation types, and revenue.

## Project Overview

- Analyzed call centre data using Microsoft Excel.
- Created Pivot Tables and Pivot Charts for performance analysis.
- Developed an interactive dashboard with KPIs, charts, and slicers.
- Analyzed call volume, customer ratings, call duration, call status, revenue, and guru performance.
- Identified trends across consultation types, websites, dates, and time periods.
- Generated data-driven insights and recommendations for hiring, training, and technology improvements.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Functions
- Data Visualization
- Dashboard
